What's x402?

x402 is an open, HTTP-native payment protocol (built by Coinbase) that lets any script or AI agent pay per request in USDC — no accounts, API keys, or subscriptions. Hit a gated endpoint without paying and you get an HTTP 402 back with the price; an x402-aware client signs a small USDC payment and retries automatically, and the data comes back in that same request.

How to pay

  1. Get a Solana wallet (Phantom, Solflare, or Coinbase Wallet configured for Solana).
  2. Fund it with a few dollars of USDC — at $0.01–$0.10 per call, that covers hundreds of requests.
  3. Point your script or agent's HTTP client at the endpoint (or use the aijobsboom-x402 MCP server) — payment happens automatically per request, no manual approval needed.

¿Qué es x402?

x402 es un protocolo de pagos abierto, nativo de HTTP (creado por Coinbase), que deja que cualquier script o agente de IA pague por consulta en USDC — sin cuentas, sin claves de API y sin suscripciones. Si llamas a un endpoint de pago sin pagar, te regresa un HTTP 402 con el precio; un cliente compatible con x402 firma un pago chico en USDC y vuelve a intentar solo, y los datos llegan en esa misma consulta.

Cómo pagar

  1. Consigue una billetera de Solana (Phantom, Solflare o Coinbase Wallet configurada para Solana).
  2. Ponle unos cuantos dólares en USDC — a $0.01–$0.10 por consulta, eso alcanza para cientos de consultas.
  3. Apunta el cliente HTTP de tu script o agente al endpoint (o usa el servidor MCP aijobsboom-x402) — el pago se hace solo en cada consulta, sin aprobarlo a mano.
